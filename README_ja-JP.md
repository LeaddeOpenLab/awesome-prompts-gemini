### キャラクターが継続的に出現する3Dタイポグラフィや視覚的パスと並んで歩き、空間内のテキスト要素とインタラクションしながらロゴの公開へと移り変わる、コマーシャルフィルムスタイルのトラッキングショット。

作者：[@taya\_mama\_AI](https://x.com/taya_mama_AI) · [元の投稿](https://x.com/taya_mama_AI/status/2096612096003965254)

シネマティック / フィルムスチル · 3D レンダリング · キャラクター · テキスト / タイポグラフィ · 配信済み

元の投稿：[@taya\_mama\_AI](https://x.com/taya_mama_AI) · [元の投稿](https://x.com/taya_mama_AI/status/2095076567416451105)

**概要:** キャラクターが継続的に出現する3Dタイポグラフィや視覚的パスと並んで歩き、空間内のテキスト要素とインタラクションしながらロゴの公開へと移り変わる、コマーシャルフィルムスタイルのトラッキングショット。

<img src="covers/2096612096003965254.jpg" alt="画像 1" width="480" />

**プロンプト**

```text
コマーシャルフィルム。

シークエンス全体を通して、初期の背景色を維持してください。

カメラは途切れることのない水平スクロール移動でキャラクターを滑らかにトラッキングし、歩行に合わせて並走します。

画面全体にテキストと連結線が段階的に現れ、連続した視覚的な経路を形成します。

キャラクターは歩きながら、周囲に現れるテキストやグラフィック要素を、同じ空間に実際に存在する物理的なオブジェクトとして認識します。前進しながらこれらの要素と自然にインタラクションを行います。ときおり近くのテキストを指先で軽くタップしたり、頭上の言葉を見上げたり、グラフィックに横目を向けたり、要素を避けるために少し横へステップしたり、要素の下をくぐり抜けたり、立ち止まって何かしらを観察したりします。

線路やビジュアルルートに似た連続したラインが、テキスト要素同士を次々と繋ぎます。リファレンス画像にあるテキストは、この繋がった経路に沿って元の順序通りに順番に現れます。

テキストやグラフィック要素は、平坦な背景の装飾のように見えてはなりません。キャラクターと同じ3次元空間内に物理的に存在しているように感じられ、説得力のある空間関係とインタラクションを備えている必要があります。

テキストを決して重複または複製させないでください。

全体のテンポは速く、リズミカルで流れるように保ちます。水平スクロール移動はシークエンスを通じて途切れることなく連続させてください。

文字化け、崩れたタイポグラフィ、スペルミス、文言の改変なしに、リファレンス画像のすべてのテキストを忠実に再現してください。

最後のトランジションでは、巨大な前景のオブジェクトまたはグラフィック要素がカメラの極めて至近を通過し、フレーム全体を完全に覆うことで、自然な前景ブラーによるワイプトランジションを生み出します。

前景のオブジェクトがフレームから外れると、シームレスに最終的なロゴ画面が現れます。

カメラワークは滑らかでダイナミック、かつ映画のように仕上げてください。

何よりもキャラクターとテキスト／グラフィック要素とのインタラクションを最優先してください。

BGM：強いビートを伴うアップテンポでリズミカルな音楽。
```
